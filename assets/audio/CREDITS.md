# Audio credits

Every sound file under `assets/audio/` comes from [Freesound](https://freesound.org).
This is a personal, non-commercial hobby project.

The files are the **high-quality Ogg Vorbis previews** Freesound generates, so each one
is a transcoded copy of the uploader's original — a derivative work, which the
attribution below covers.

> `sfx/chest_opened.ogg.broken` and `sfx/door_unlock.ogg.broken` are two leftovers that
> were in the tree beforehand: byte-identical M4A files with a `.ogg` extension, of
> unknown origin. Both slots have been refilled from Freesound. Delete the leftovers.
